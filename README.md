Этап 1. REPL
Описание
Минимальный прототип эмулятора языка оболочки ОС. Реализован в виде GUI-приложения (не консольного) на Go с использованием библиотеки Fyne.

На этом этапе команды ls и cd являются заглушками: они не выполняют реальных файловых операций, а лишь выводят своё имя и переданные аргументы. Полноценная логика появится на этапе 4, когда будет подключена виртуальная файловая система (этап 3).

Функциональность
Графический интерфейс: поле ввода команд и область вывода результатов
Заголовок окна отображает имя VFS (пока заглушка — реальное имя подставится после загрузки VFS на этапе 3)
Парсер команд раскрывает переменные окружения реальной ОС (например, $HOME) перед выполнением команды
Обработка ошибок: неизвестная команда и недопустимый аргумент не приводят к падению приложения — выводится сообщение об ошибке
Команды-заглушки: ls, cd — печатают своё имя и полученные аргументы
Команда exit — корректно закрывает приложение
Структура проекта
src/
├── main.go                    — точка входа, инициализация GUI
├── internal/
│   ├── command/                — регистрация команд и их выполнение
│   └── parser/                 — разбор введённой строки, раскрытие $VAR
tests/
└── stage1/
├── manual_commands.txt     — чек-лист команд для ручной проверки
└── run_stage1.sh           — сборка и запуск приложения
Запуск
cd src
go build -o vfs-shell .
./vfs-shell
Либо через готовый скрипт:

sh tests/stage1/run_stage1.sh
Проверка
Скриптов автозапуска на этом этапе ещё нет (появятся на этапе 2), поэтому проверка выполняется вручную: команды из tests/stage1/manual_commands.txt вводятся по очереди в открывшемся окне.

Проверяемые случаи:

#	Команда	Ожидаемый результат
1	ls	Выводит ls: args = []
2	ls arg1 arg2	Выводит ls: args = [arg1 arg2]
3	cd arg1	Выводит cd: args = [arg1]
4	cd $HOME	$HOME заменяется на реальный путь из ОС
5	foobar	Ошибка: неизвестная команда, приложение не падает
6	ls unknown_flag	Ошибка: недопустимый аргумент (если задан белый список)
7	exit	Окно закрывается штатно
Зависимости
go get fyne.io/fyne/v2
Для сборки Fyne на Linux дополнительно требуются системные библиотеки:

sudo apt install -y gcc libgl1-mesa-dev xorg-dev libxkbcommon-dev libwayland-dev pkg-config
