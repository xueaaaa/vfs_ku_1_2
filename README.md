# Этап 2. Конфигурация

## Описание

На этом этапе эмулятор научился принимать параметры командной строки
и выполнять стартовый скрипт автоматически при запуске — без участия
пользователя, как будто команды вводятся вручную одна за другой.

## Функциональность

- Параметры командной строки:
  - `--vfs` — путь к файлу VFS (пока только принимается, реальная
    загрузка появится на этапе 3)
  - `--script` — путь к стартовому скрипту
- Стартовый скрипт — текстовый файл, одна команда на строку
- Поддержка комментариев в скрипте: строки, начинающиеся с `//`,
  игнорируются при выполнении
- Пустые строки в скрипте пропускаются
- Обработка ошибок при выполнении стартового скрипта:
  - несуществующий путь к скрипту не приводит к падению приложения
  - ошибка в отдельной команде скрипта (неизвестная команда,
    недопустимый аргумент) не прерывает выполнение остальных строк
- Каждая выполняемая строка скрипта выводится в интерфейс перед
  результатом — имитация диалога с пользователем

## Структура проекта

```
src/
├── main.go
└── internal/
    ├── command/
    ├── config/                 — парсинг флагов командной строки
    ├── executor/
    └── parser/
tests/
└── stage2/
    ├── script_basic.txt        — валидный сценарий
    ├── script_comments.txt     — сценарий из одних комментариев
    ├── script_errors.txt       — сценарий с ошибками
    ├── script_empty.txt        — пустой файл сценария
    └── run_stage2.sh           — прогон всех случаев
```

## Запуск

```bash
cd src
go build -o vfs-shell .

# без параметров
./vfs-shell

# с валидным скриптом
./vfs-shell --script=../tests/stage2/script_basic.txt

# с флагом vfs (пока только принимается, не используется)
./vfs-shell --vfs=../tests/stage3/vfs_minimal.xml
```

Либо через готовый скрипт, покрывающий все случаи сразу:

```bash
sh tests/stage2/run_stage2.sh
```

## Проверка

| # | Сценарий                                         | Ожидаемый результат                                             |
|---|---------------------------------------------------|-------------------------------------------------------------------|
| 1 | Запуск без флагов                                 | Окно открывается, скрипт не выполняется                          |
| 2 | `--script=script_basic.txt`                       | Все команды выполняются последовательно                          |
| 3 | `--script=script_comments.txt`                    | Ничего не выполняется, комментарии пропущены                     |
| 4 | `--script=script_errors.txt`                      | Ошибочные строки выводят сообщение об ошибке, скрипт не прерывается |
| 5 | `--script=script_empty.txt`                       | Пустой файл, ничего не выполняется, приложение не падает          |
| 6 | `--script=nonexistent.txt`                        | Сообщение об ошибке открытия файла, окно остаётся открытым        |
| 7 | `--vfs=../tests/stage3/vfs_minimal.xml`           | Флаг принимается и выводится, реальная загрузка ещё не выполняется |

## Известные ограничения этапа

`--vfs` на этом этапе только парсится и выводится в лог — сама загрузка
и работа с деревом VFS реализована на этапе 3.
