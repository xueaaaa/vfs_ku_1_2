# Этап 5. Дополнительные команды

## Описание

Завершающий этап: реализованы команды `rm` и `chown` — в отличие от
всех предыдущих команд, они изменяют состояние VFS в памяти
(структуру дерева и метаданные файлов), а не только читают его.
Исходный XML-файл VFS при этом не затрагивается — изменения существуют
только в рамках текущего запуска приложения.

## Функциональность

- `rm <путь>...` — удаляет файл или директорию по имени или пути
  (абсолютному/относительному), можно несколько операндов:
  - сначала ищет среди файлов, затем среди вложенных директорий
  - нельзя удалить `.`, `..` и директорию, внутри которой находится
    текущая позиция — выводится ошибка
  - удаление физически убирает элемент из соответствующего слайса
    (`Files`/`Subdirs`) в дереве, изменение сразу видно в последующем `ls`
  - попытка удалить несуществующий элемент — ошибка, без падения
    приложения
- `ls -l` показывает владельца файла (колонка между типом и размером)
- `chown <владелец> <файл>` — меняет владельца файла (файл можно указать путём):
  - требует ровно два аргумента, при нехватке — ошибка
  - работает через указатель на файл в дереве, поэтому изменение владельца сохраняется в VFS в памяти
  - попытка сменить владельца несуществующего файла — ошибка, без
    падения приложения

## Проверка

| # | Команда в сценарии            | Ожидаемый результат                                          |
|---|----------------------------------|------------------------------------------------------------------|
| 1 | `rm a.txt` → `ls`                | Файл `a.txt` больше не отображается в списке                     |
| 2 | `rm b.txt` → `ls`                | Файл `b.txt` также удалён                                        |
| 3 | `chown user1 notes.txt`          | Владелец файла изменён (видно через `ls` с выводом владельца     |
|   |                                  | или отдельную проверку, если такая реализована)                  |
| 4 | `rm a.txt` (повторно)            | Ошибка "файл не найден", приложение не падает                    |
| 5 | `chown user1` (без файла)        | Ошибка "не хватает аргументов", приложение не падает              |
| 6 | `chown user1 nowhere.txt`        | Ошибка "файл не найден", приложение не падает                    |
| 7 | `rm home` (директория)           | Директория удаляется из дерева целиком                           |
| 8 | `cd /home/user` → `rm documents/deep.txt` | Относительный путь работает от текущей директории          |
| 9 | `rm /home/user` из `/home/user`  | Ошибка: нельзя удалить директорию, в которой находишься           |

## Итог по всем этапам

На этом этапе завершена реализация всех команд, заявленных в задании
для варианта №2: `ls`, `cd`, `rev`, `clear`, `rm`, `chown`, а также
`exit`. Эмулятор поддерживает параметры командной строки, стартовые
скрипты с комментариями, загрузку VFS из XML и корректную обработку
ошибок на каждом уровне (парсинг команд, навигация по VFS, работа с
файлами).
